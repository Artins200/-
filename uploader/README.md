# Страница загрузки игры

Один файл — [`index.html`](index.html). Открывается двойным щелчком в браузере,
интернет нужен только для отправки в GitHub.

## Что умеет

- **Перетаскивание файлов и папок.** Можно кинуть весь проект целиком.
- **`.rbxlx` / `.rbxmx`** — разбирает XML места и достаёт все `Script`,
  `LocalScript`, `ModuleScript` в отдельные файлы:
  ```
  game/scripts/Моё_место/Workspace/Station/Door.server.lua
  game/scripts/Моё_место/ReplicatedStorage/StoryData.lua
  game/scripts/Моё_место/_manifest.json
  ```
  Суффиксы как в Rojo: `.server.lua`, `.client.lua`, `.lua`.
- **`.zip`** — распаковывает (stored и deflate) и рекурсивно обрабатывает
  найденные внутри `.rbxlx`, плюс переносит тексты, картинки и звуки.
- **`Скачать .zip с результатом`** — тот же набор файлов локально, если токена нет.
- **GitHub** — коммитит файлы через Contents API, обновляя существующие по `sha`.

## Чего не умеет

- **`.rbxl` / `.rbxm`** — бинарные форматы, в браузере не разбираются. Файл
  загрузится как есть, но скрипты из него не извлекутся.
  В Studio: **File → Save As → Roblox Location Files (*.rbxlx)**.
- **Файлы больше ~50 МБ** — Contents API не любит большие тела запроса.
  Такой файл лучше положить в репозиторий через Git LFS.

## Токен

1. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new.
2. Repository access: только этот репозиторий.
3. Permissions → **Contents: Read and write**. Больше ничего не нужно.
4. Вставь токен в поле «Токен». Он остаётся в браузере: запросы идут только на
   `api.github.com`.

Токен не нужен, если пользуешься «Скачать .zip» и заливаешь архив руками.

## Проверка

Логика страницы (разбор `.rbxlx`, zip, пути, GitHub-запросы) вынесена между
маркерами `CORE START` / `CORE END` и тестируется без браузера:

```bash
npm run test:uploader     # 41 проверка
```

Тест берёт код **прямо из `index.html`**, так что проверяется именно то, что
выполняется у тебя.
