Положить игру в репозиторий

Перетащи сюда .rbxlx, .rbxl (Studio сохранит как XML — лучше .rbxlx), .zip с проектом или отдельные .lua/.luau скрипты. Страница разложит файлы по папкам, вытащит скрипты из места и закоммитит всё в GitHub. Файл остаётся у тебя в браузере — уходит только то, что ты сам отправишь.

Шаг 1

Файлы

Можно кидать папкой целиком. Поддерживаются .rbxlx (и .rbxmx), .zip, .lua, .luau, .json, .toml, .txt, .md, картинки и звуки.

Шаг 2

GitHub

Нужен fine-grained token с доступом Contents: Read and write только к этому репозиторию. Токен живёт в памяти вкладки; «запомнить» кладёт его в localStorage этого браузера.

Если токена нет — нажми «Скачать .zip с результатом» и закинь архив в репозиторий руками. Страница не отправляет файлы никуда, кроме api.github.com.
Шаг 3

После загрузки

.rbxl — бинарный формат, его нельзя разобрать в браузере. В Studio: File → Save As → Roblox Location Files (*.rbxlx). Сам файл загрузить можно, но скрипты из него не извлекутся.

Скрипты лягут в game/scripts/<имя места>/… с суффиксами .server.lua / .client.lua / .lua — как в Rojo. Дальше сюжет правится в story/story.json, а npm run build пересобирает StoryData.lua и граф. Детали — в docs/СЮЖЕТ.md.
