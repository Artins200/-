# Станция «Тишина» — визуальная новелла для Roblox

Сюжетный каркас + рабочий движок + страница загрузки файла игры в репозиторий.

**Сюжет:** техник прилетает на станцию, которая четыре месяца молчит, и находит
внутри школу, которую ИИ переигрывает тринадцатый раз. Там живут два Артёма —
оригинал и копия, собранная из его памяти. 95 сцен, 4 акта, 808 слова — короткие реплики, а не описания; 3 концовки;
в финале один из двоих умирает всегда.

Сюжет собран по реальной карте игры `neirogh.rbxl`: 225 вывесок-реплик разложены
по координатам в 9 кластеров, найдены 5 авторских телепортов и полоса из 50 огней —
это и есть арена последней главы. Разбор: [`docs/КАРТА.md`](docs/КАРТА.md).

**Никакого интерфейса.** Ни одного `ScreenGui` и ни одной таблички над головой:
сцена — это комната из моделей самого плейса: 2–4 копии персонажей стоят группой,
лицом друг к другу, с именами над головой, как на карте.
Реплики короткие и идут по очереди на вывеске (`SurfaceGui` на части, как 225
вывесок карты). Действия не описываются словами — персонаж их **играет** (`Pose.lua`):
замах, шаг к собеседнику, удар, блок, захват за горло, падение на пол. Портал в конце комнаты
открывается только когда сцена доиграна.

## Быстрый старт

```bash
npm install
npm run build     # story.json → StoryData.lua + docs/ГРАФ.md, с проверками
npm test          # граф + карта + синтаксис + 77 логики + 57 поз + 116 плеера + 34 карты + 65 файла места + 41 загрузчика
npm run map       # пересобрать карту из neirogh.rbxl (нужен rbx-dom) и пересчитать связи
npm run place     # собрать один файл neirogh.story.rbxl: карта + крыло + скрипты
npm run scheme    # нарисовать docs/схема-крыла.svg
npm run serve     # сервер: /uploader/ (загрузка игры) и /story/preview.html (читалка сюжета)
```

Играть: скачать `neirogh.story.rbxl` → Studio → **Play**. Сборка и разбор —
[`docs/КАК_ЭТО_СВЯЗАТЬ.md`](docs/КАК_ЭТО_СВЯЗАТЬ.md).

## Один файл .rbxl

[`neirogh.story.rbxl`](neirogh.story.rbxl) — исходная карта (42 265 объектов)
плюс крыло сюжета из 95 комнат.

1. Скачай файл и открой в Roblox Studio (`File → Open from File`).
2. Нажми **Play** — ты в первой комнате.
3. Дальше только WASD: персонаж сцены, вывеска с текстом, оранжевая площадка
   портала. Наступил — переехал в следующую комнату.

| Что | Где |
|---|---|
| 95 комнат-сцен | `Workspace.StoryWing` → `Scene_<id>` |
| 2–4 актёра в комнате | копии моделей карты стоят группой, лицом друг к другу, имя видно над головой (`Humanoid.DisplayName`), подкрашены под персонажа |
| сплошной пол | `Workspace.StoryWing.Floor` на всю линию комнат + точка появления |
| реплики | часть `Sign` с `SurfaceGui`; сервер меняет текст по очереди |
| позы | `Pose.lua`: `step`, `punch`, `throw`, `choke`, `block`, `grab`, `kneel`, `fall` — руки, ноги, корпус, падение |
| драка | замах → шаг к собеседнику → удар → второй закрывается → возврат в стойку |
| порталы между комнатами | `Portal_<id>` — «Teleport One Way» из карты, открывается после сцены |
| портал после финала | `Portal_Final` → огненная арена `[-201.6, 7.2, 6.1]` |
| скрипты | `ReplicatedStorage/Shared` (StoryData, StoryEngine, Pose), `ServerScriptService/StoryWorld` |

Схема: [`docs/схема-крыла.svg`](docs/схема-крыла.svg).

Пересобрать после правок сюжета или скриптов:

```bash
npm i --no-save rbx-dom
npm run build   # story.json → StoryData.lua
npm run place   # → neirogh.story.rbxl
```

Сборка идемпотентна: старое крыло и скрипты удаляются перед вставкой.
`npm test` пересобирает файл и проверяет, что он не отстал от `roblox/src`.

## Загрузить свою игру

1. Открой [`uploader/index.html`](uploader/index.html) в браузере.
2. Перетащи `.rbxlx` (или `.zip`, или папку со скриптами).
   Страница вытащит все скрипты места в `game/scripts/<место>/…`
   с Rojo-суффиксами и покажет, что получится.
3. Вставь fine-grained токен GitHub (`Contents: Read and write`) и нажми
   «Закоммитить». Токен остаётся в браузере.
4. Нет токена? «Скачать .zip с результатом» и залей архив руками.

Подробно: [`uploader/README.md`](uploader/README.md).

## Как проверяется сюжет

`npm run build` строит граф сцен и падает, если есть:

- висячая ссылка `goto` на несуществующую сцену;
- недостижимая сцена или недостижимая концовка;
- тупик (сцена без выборов и без концовки);
- флаг, который ставится, но нигде не проверяется («ружьё не стреляет»);
- предмет, который выдаётся, но ни для чего не нужен.

Отдельно проверяется карта (`tools/test-place-map.mjs`): координаты конечные,
все вывески разложены по кластерам, огонь — одна полоса, а цель телепорта
совпадает с центром огня в `layout.json`.

И собранный файл (`tools/test-place-file.mjs`): `.rbxl` читается как place,
в крыле ровно 95 комнат, в каждой группа актёров с именами и вывеска с репликами, реплики
короткие и с позами, под крылом сплошной пол и точка появления, порталы идут
цепочкой и открываются после сцены, последний ведёт на арену огня,
своих `ScreenGui`/`BillboardGui` и клиентских скриптов нет.

Сюжет правится в JSON, Luau-данные и граф пересобираются автоматически.
