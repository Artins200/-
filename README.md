# Станция «Тишина» — визуальная новелла для Roblox

Сюжетный каркас + рабочий движок + страница загрузки файла игры в репозиторий.

**Демо-сюжет:** техник прилетает на станцию, которая четыре месяца молчит, и
слышит в эфире голос мёртвой женщины. 29 сцен, 3 концовки, флаги и предметы,
все «ружья» проверены сборщиком.

## Быстрый старт

```bash
npm install
npm run build     # story.json → StoryData.lua + docs/ГРАФ.md, с проверками
npm test          # граф + синтаксис Luau + 82 теста логики + 41 тест загрузчика
npm run serve     # сервер: /uploader/ (загрузка игры) и /story/preview.html (чтение сюжета)
```

Играть в демо: `rojo serve roblox/default.project.json` → Studio → Rojo Connect.
Без Rojo — инструкция в [`docs/КАК_ЭТО_СВЯЗАТЬ.md`](docs/КАК_ЭТО_СВЯЗАТЬ.md).

## Загрузить свою игру

1. Открой [`uploader/index.html`](uploader/index.html) в браузере.
2. Перетащи `.rbxlx` (или `.zip`, или папку со скриптами).
   Страница вытащит все скрипты места в `game/scripts/<место>/…`
   с Rojo-суффиксами и покажет, что получится.
3. Вставь fine-grained токен GitHub (`Contents: Read and write`) и нажми
   «Закоммитить». Токен остаётся в браузере.
4. Нет токена? «Скачать .zip с результатом» и залей архив руками.

Подробно: [`uploader/README.md`](uploader/README.md).

## Как проверяется сюжет

`npm run build` строит граф сцен и падает, если есть:

- висячая ссылка `goto` на несуществующую сцену;
- недостижимая сцена или недостижимая концовка;
- тупик (сцена без выборов и без концовки);
- флаг, который ставится, но нигде не проверяется («ружьё не выстрелило»);
- предмет, который выдаётся, но ни для чего не нужен.

Сюжет правится в JSON, Luau-данные и граф пересобираются автоматически.
