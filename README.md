# Станция «Тишина» — визуальная новелла для Roblox

Сюжетный каркас + рабочий движок + страница загрузки файла игры в репозиторий.

**Сюжет:** техник прилетает на станцию, которая четыре месяца молчит, и находит
внутри школу, которую ИИ переигрывает тринадцатый раз. Там живут два Артёма —
оригинал и копия, собранная из его памяти. 95 сцен, 4 акта, 5522 слова, 3 концовки;
в финале один из двоих умирает всегда.

Сюжет собран по реальной карте игры `neirogh.rbxl`: 225 вывесок-реплик разложены
по координатам в 9 кластеров, найдены 5 авторских телепортов и полоса из 50 огней —
это и есть арена последней главы. Разбор: [`docs/КАРТА.md`](docs/КАРТА.md).

**Это не меню поверх игры.** Сцены расставлены по карте: у каждой есть точка в мире
и, если повезло, живой НПС с карты — Демид, Ваня, Некит, Sans, Arto. Игрок идёт
вперёд, у метки сцена срабатывает сама, реплика появляется внизу экрана, а не
закрывает собой школу. В финале начинается драка, телепорт физически переносит
персонажа на арену из пятидесяти очагов.

## Быстрый старт

```bash
npm install
npm run build     # story.json → StoryData.lua + docs/ГРАФ.md, с проверками
npm test          # граф + карта + синтаксис Luau + 94 логики + 104 плеера + 34 карты + 31 файла места + 41 загрузчика
npm run map       # пересобрать карту из neirogh.rbxl (нужен rbx-dom) и пересчитать связи
npm run place     # собрать ОДИН файл neirogh.story.rbxl: карта + вся новелла внутри
npm run route     # нарисовать docs/карта-маршрут.svg
npm run serve     # сервер: /uploader/ (загрузка игры) и /story/preview.html (чтение сюжета)
```

Играть в демо: `rojo serve roblox/default.project.json` → Studio → Rojo Connect.
Без Rojo — инструкция в [`docs/КАК_ЭТО_СВЯЗАТЬ.md`](docs/КАК_ЭТО_СВЯЗАТЬ.md).

## Один файл .rbxl

[`neirogh.story.rbxl`](neirogh.story.rbxl) — всё в одном файле: исходная карта
(42 265 объектов: школа, коридор вывесок, 50 очагов огня, авторские телепорты)
плюс движок новеллы.

1. Скачай файл и открой его в Roblox Studio (`File → Open from File`).
2. Нажми **Play**. Ты появляешься у спавна карты; впереди — голубая метка `▼`
   и луч света: это точка текущей сцены. Идёшь — сцена срабатывает.
3. Ставить руками ничего не нужно: `ReplicatedStorage/Shared` (5 модулей),
   `ServerScriptService/StoryServer` и `StarterPlayer/StarterPlayerScripts/StoryClient`
   уже внутри.

Управление: **идти** — WASD, **выбрать** — кнопки внизу, **ударить** — `F`,
**телепорт** — кнопка «ШАГНУТЬ В ОГОНЬ» или `Space`.

Как это устроено:

| Что | Где |
|---|---|
| точка каждой сцены в мире | [`WorldKit.lua`](roblox/src/ReplicatedStorage/Shared/WorldKit.lua) (`world.plan`, маршрут по актам) |
| карта маршрута | [`docs/карта-маршрут.svg`](docs/карта-маршрут.svg) — вид сверху: 95 сцен, кластеры, НПС, арена |
| живые НПС с карты (427 моделей с `Humanoid`) | `game/place-map.json` → `layout.json` → `StoryData.world.cast` |
| авто-переход «дошёл — сцена сменилась» | `StoryServer.server.lua`, цикл 0.25 с |
| метка `▼`, луч, HUD, субтитры | `StoryClient.client.lua` |
| драка: тряска, урон, отлёт НПС | `StoryServer` (`Strike`, `isFight`) |

Пересобрать после правок сюжета или скриптов:

```bash
npm i --no-save rbx-dom   # разбор и запись .rbxl
npm run build             # story.json → StoryData.lua
npm run place             # → neirogh.story.rbxl
```

Сборка идемпотентна: повторный запуск не плодит дубликаты скриптов.
`npm test` сам пересобирает файл и проверяет, что он не отстал от `roblox/src`.

## Загрузить свою игру

1. Открой [`uploader/index.html`](uploader/index.html) в браузере.
2. Перетащи `.rbxlx` (или `.zip`, или папку со скриптами).
   Страница вытащит все скрипты места в `game/scripts/<место>/…`
   с Rojo-суффиксами и покажет, что получится.
3. Вставь fine-grained токен GitHub (`Contents: Read and write`) и нажми
   «Закоммитить». Токен остаётся в браузере.
4. Нет токена? «Скачать .zip с результатом» и залей архив руками.

Подробно: [`uploader/README.md`](uploader/README.md).

## Как проверяется сюжет

`npm run build` строит граф сцен и падает, если есть:

- висячая ссылка `goto` на несуществующую сцену;
- недостижимая сцена или недостижимая концовка;
- тупик (сцена без выборов и без концовки);
- флаг, который ставится, но нигде не проверяется («ружьё не стреляет»);
- предмет, который выдаётся, но ни для чего не нужен.

Отдельно проверяется карта (`tools/test-place-map.mjs`): координаты конечные,
все вывески разложены по кластерам, огонь — одна полоса, а цель телепорта
совпадает с центром огня в `layout.json`.

И собранный файл (`tools/test-place-file.mjs`): бинарный заголовок `.rbxl`,
DataModel в корне, 4 модуля в `ReplicatedStorage/Shared`, серверный и клиентский
скрипты на своих местах, исходники совпадают с `roblox/src`, геометрия карты и
огни не потеряны, `StoryServer` не размножился.

Сюжет правится в JSON, Luau-данные и граф пересобираются автоматически.
