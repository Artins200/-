# Как это собрано и как менять

Вся новелла идёт по карте: комнаты, персонажи, вывески, порталы. Экранов,
кнопок и субтитров нет вообще — ни `ScreenGui`, ни `BillboardGui`.

---

## 1. Что где лежит

```
story/story.json                 сюжет: сцены, персонажи, текст, концовки
tools/build-story.mjs            проверка + StoryData.lua + docs/ГРАФ.md
tools/world-builder.mjs          сборка крыла: комнаты, персонажи, вывески, порталы
tools/build-place.mjs            карта + крыло + скрипты → один neirogh.story.rbxl
tools/build-world.mjs            только крыло → neirogh.world.rbxl + game/world.json
tools/render-wing.mjs            схема крыла → docs/схема-крыла.svg
tools/test-place-file.mjs        проверка собранного файла

roblox/src/ReplicatedStorage/Shared/StoryData.lua    ← генерируется
roblox/src/ReplicatedStorage/Shared/StoryEngine.lua  ← текст, флаги, предметы
roblox/src/ServerScriptService/StoryWorld.server.lua ← единственный скрипт игры

neirogh.rbxl                     исходная карта (не трогаем)
neirogh.story.rbxl               готовый файл: карта + крыло + скрипты
game/world.json                  раскладка крыла: комнаты, координаты, порталы
game/place-map.json              координаты и вывески исходной карты
game/layout.json                 связанность моделей и арена финала
```

Пересобрать:

```bash
npm i --no-save rbx-dom   # разбор и запись .rbxl
npm run build             # story.json → StoryData.lua
npm run place             # → neirogh.story.rbxl (карта + крыло + скрипты)
npm run scheme            # → docs/схема-крыла.svg
```

## 2. Что внутри файла

| Куда | Что |
|---|---|
| `Workspace.StoryWing` | 95 комнат-сцен, в каждой персонаж и вывеска, между ними порталы |
| `ReplicatedStorage.Shared` | `StoryData`, `StoryEngine` |
| `ServerScriptService` | `StoryWorld` — один Script, `LocalScript` нет ни одного |

Открываешь файл в Studio → **Play** → игрок появляется в первой комнате.
Дальше только ходить: впереди площадка входа, персонаж, вывеска с текстом и
оранжевая площадка портала. Наступил на портал — он перенёс в следующую комнату
и открыл следующую вывеску.

## 3. Крыло: как сцены лежат на карте

`tools/world-builder.mjs` берёт из `neirogh.rbxl` готовые модели этого плейса и
ничего не рисует от себя:

| Что берём | Откуда | Куда идёт |
|---|---|---|
| комната | первая модель `Room` | `Scene_<id>`, по одной на сцену |
| персонаж | модель с `Humanoid` нужного имени | внутрь комнаты, вперёд лицом к входу |
| вывеска | часть `Sign` с `SurfaceGui` | внутрь комнаты, текст сцены |
| портал | папка `Teleport One Way` | между комнатами, со скриптом `Ignore` внутри |

Раскладка:

- шаг между комнатами — ширина комнаты + 14 юнитов (`base.step`), поэтому пешком
  из комнаты в комнату не перейти, только порталом;
- линия идёт от `base.x = 620` к `base.z = -1500` и дальше на запад;
- внутри комнаты: `Arrival` (голубая площадка) → персонаж → `Sign` → `Exit`
  (оранжевая площадка) → `Portal_<id>`.

Всё это выгружается в `game/world.json`:

```json
{
  "scenes": [
    {
      "id": "start", "index": 0, "act": 1,
      "character": "Артём", "room": "Scene_start",
      "sign": [626, 5.6, -1500], "arrival": [605, 3.4, -1500], "exit": [636, 0.6, -1500]
    }
  ],
  "portals": [{ "id": "Portal_start", "from": [636, 0.6, -1500], "to": [605, 3.4, -1440], "next": "hull" }],
  "nextLocation": [-201.6, 7.2, 6.1]
}
```

### Портал после финальной главы

`Portal_Final` стоит в конце последней комнаты и ведёт в следующую локацию —
на огненную арену `[-201.6, 7.2, 6.1]` (центр пятидесяти очагов из `meta.map`).
Поменять точку: `story.meta.map.arena.fire` и `npm run place`.

## 4. Что делает сервер

`StoryWorld.server.lua` — один скрипт, без клиентской части.

1. Собирает список сцен из `StoryData.order` и находит `Scene_<id>` в крыле.
2. Гасит все вывески, кроме первой: игрок видит только свою сцену.
3. На появление игрока ставит его на `Arrival` текущей сцены.
4. Слушает `Touched` площадки каждого портала: срабатывает только портал той
   сцены, на которой игрок сейчас стоит, — перескочить нельзя.
5. Меняет свет по акту (рассвет / день / закат / красная ночь) — тоже без интерфейса.
6. В акте IV персонаж комнаты подходит к игроку, если тот рядом.

Сам перенос делает скрипт `Ignore` внутри папки портала — тот же, что в карте:

```lua
TeleportPart1.Touched:Connect(function(hit)
    local w = hit.Parent:FindFirstChild("HumanoidRootPart")
    if w then w.CFrame = TeleportPart2.CFrame + Vector3.new(0, 5, 0) end
end)
```

Клиентских скриптов новеллы нет, поэтому играть может любой игрок без загрузки UI.

## 5. Как менять сюжет и раскладку

**Текст сцены.** Правь `story/story.json` → `npm run build && npm run place`.
Текст попадает на вывеску, персонаж сцены — по полю `speaker`.

**Другой персонаж в комнате.** В сцене `speaker` — ключ из `characters`.
`world-builder` ищет модель с таким именем на карте (`Демид`, `Ваня`, `Некит`,
`Артинс`, `Лира`, `МАМА`…); если модели нет — ставит Артёма.

**Порядок и состав.** Порядок комнат = порядок `nodes` в `story.json`.

**Геометрия крыла.** В `tools/world-builder.mjs`: `STEP`, `BASE_X`, `BASE_Z`,
положение персонажа, вывески и площадок внутри комнаты.

**Следующая локация после финала.** `meta.map.arena.fire` в `story.json`.

## 6. Если хочешь вживить это в своё место

1. Скопируй `Workspace.StoryWing` из собранного файла в своё место.
2. Положи `StoryData` и `StoryEngine` в `ReplicatedStorage.Shared`.
3. Положи `StoryWorld` в `ServerScriptService`.
4. Если комнаты называются иначе — поправь поиск `Scene_<id>` в начале скрипта.

Свой UI не нужен: текст живёт на вывесках, навигация — площадками и порталами.

## 7. Частые ошибки

| Симптом | Причина |
|---|---|
| Игрок стоит в первой комнате и ничего не происходит | не наступил на оранжевую площадку `Exit` / портал не найден |
| Портал не переносит | у папки нет `TeleportPart2` или скрипт `Ignore` отключён |
| Текст сцены пустой | в `story.json` пустой `text` — сборщик это ловит |
| Персонаж стоит не тот | на карте нет модели с таким именем — проверь `game/place-map.json` |
| Вывеска не видна | у вывески `SurfaceGui.Enabled = false` (включена только текущая сцена) |
| Сцены не совпали с графом | забыл `npm run build` после правки JSON |
| Файл отстал от `roblox/src` | `npm run place` |
