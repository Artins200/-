# Здесь лежит игра

Сюда попадает загруженный файл места и распакованные из него скрипты:

```
game/
  Моё_место.rbxlx              сам файл (если включено «сохранить и сам файл»)
  scripts/
    Моё_место/
      Workspace/...
      ReplicatedStorage/...
      _manifest.json           список классов, путей и числа строк
```

Загрузить файл: открой [`../uploader/index.html`](../uploader/index.html)
в браузере, перетащи `.rbxlx` и закоммить (нужен GitHub-токен с `Contents: write`).
Без токена страница соберёт `.zip`, который можно положить сюда вручную.

> Бинарный `.rbxl` сохранится, но скрипты из него не извлекутся — в Studio
> используй **File → Save As → `.rbxlx`**.

## Карта места

`place-map.json` и `layout.json` — не «ещё один загрузчик», а разбор координат:

```
game/
  place-map.json    спавн, зоны, персонажи, телепорты, 50 огней, 225 вывесок
  layout.json       9 кластеров текста, рёбра «рядом»/«телепорт», арена финала
```

Пересобрать: `npm run map` (нужен пакет `rbx-dom`: `npm i --no-save rbx-dom`).
Скрипт `tools/place-import.mjs` читает бинарный `.rbxl` напрямую, поэтому
пересохранять место в `.rbxlx` не требуется.

После загрузки: см. [`../docs/КАК_ЭТО_СВЯЗАТЬ.md`](../docs/КАК_ЭТО_СВЯЗАТЬ.md) —
как подключить движок к своему месту и что связать в сюжете.
