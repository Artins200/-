# Здесь лежит игра

Сюда попадает загруженный файл места и распакованные из него скрипты:

```
game/
  Моё_место.rbxlx              сам файл (если включено «сохранить и сам файл»)
  scripts/
    Моё_место/
      Workspace/...
      ReplicatedStorage/...
      _manifest.json           список классов, путей и числа строк
```

Загрузить файл: открой [`../uploader/index.html`](../uploader/index.html)
в браузере, перетащи `.rbxlx` и закоммить (нужен GitHub-токен с `Contents: write`).
Без токена страница соберёт `.zip`, который можно положить сюда вручную.

> Бинарный `.rbxl` сохранится, но скрипты из него не извлекутся — в Studio
> используй **File → Save As → `.rbxlx`**.

## Собранное крыло

`world.json` — раскладка готового места: 95 комнат, у каждой `actors`
(двое: кто говорит + кто слушает, лицом друг к другу), `lines` (2–3 короткие
реплики с позой), `sign`, `arrival`, `exit`, `portal`. Общие поля:
`floor` — верх плиты, по которой ходят, `spawn` — точка появления в начале крыла,
`nextLocation` — куда ведёт `Portal_Final`.

Действия в тексте не описываются: сервер берёт `pose` реплики и ставит модель
(`Pose.lua` — `step`, `punch`, `throw`, `block`, `grab`, `choke`, `kneel`, `fall`).

## Карта места

`place-map.json` и `layout.json` — не «ещё один загрузчик», а разбор координат:

```
game/
  place-map.json    спавн, зоны, персонажи, телепорты, 50 огней, 225 вывесок
  layout.json       9 кластеров текста, рёбра «рядом»/«телепорт», арена финала
```

Пересобрать: `npm run map` (нужен пакет `rbx-dom`: `npm i --no-save rbx-dom`).
Скрипт `tools/place-import.mjs` читает бинарный `.rbxl` напрямую, поэтому
пересохранять место в `.rbxlx` не требуется.

## Готовый файл с сюжетом

`../neirogh.story.rbxl` — та же карта плюс `Workspace.StoryWing`: 95 комнат,
в каждой копия модели персонажа и вывеска с текстом, между ними порталы.
Открывается в Studio и играется по **Play**, интерфейса нет. Собирается одной командой:

```bash
npm run place
```

Внутри: `Workspace.StoryWing` (крыло), `ReplicatedStorage/Shared` (StoryData,
StoryEngine) и `ServerScriptService/StoryWorld`. Карта при сборке не меняется —
только добавляются эти узлы, поэтому координаты арены и авторских телепортов
остаются верными. Раскладка крыла выгружается в `world.json`.

Сразу после сборки: см. [`../docs/КАК_ЭТО_СВЯЗАТЬ.md`](../docs/КАК_ЭТО_СВЯЗАТЬ.md) —
как подключить движок к своему месту и что связать в сюжете.
